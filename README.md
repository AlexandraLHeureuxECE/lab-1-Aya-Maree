# SE4471 – Lab 1: Tic Tac Toe

This repository contains a simple web-based Tic Tac Toe game developed for SE4471 Lab 1.

## Live Demo
https://alexandralheureuxece.github.io/lab-1-Aya-Maree/

## Features
- 3×3 Tic Tac Toe board
- Two-player turn-based gameplay (X and O)
- Win and draw detection
- Visual highlight of winning cells
- Restart button without page refresh
- Keyboard support for accessibility

## How to Run Locally
1. Clone the repository:
git clone https://github.com/alexandralheureuxece/lab-1-Aya-Maree.git

2. Open `index.html` in any modern web browser.

No additional setup or dependencies are required.
